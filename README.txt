README

> **ProfomaMaker** is an all-in-one, full-stack web application designed for hotels, resorts, and banquet spaces to generate, manage, preview, and print official bilingual (English & Arabic) proforma invoices.
>
> Built with **React 18**, **Express.js**, and **PostgreSQL**, it features real-time financial calculations (5% Municipality Fee & 15% ZATCA VAT), item description presets, customer database bulk CSV import/export, filtered PDF summary reports, and customizable AAA high-contrast themes & typography fonts.



### ⭐ Key Features Bullet List *(Great for GitHub Repository About)*
- 🏨 **Multi-Category Invoicing**: Room Stays, Events/Banquets, and Miscellaneous services.
- 🌐 **Bilingual & RTL**: Switch instantly between Bilingual (En/Ar), English Only, or Arabic Only (with RTL layout).
- 🖨️ **A4 PDF Printing**: Clean document isolation with dynamic timestamped footers.
- 🏷️ **Line Item Presets**: Pre-define room rates and banquet packages for quick 1-click selection.
- 👥 **Customer Database**: Bulk CSV import/export with Excel formula protection for 15-digit ZATCA VAT numbers.
- 📊 **Filtered History Reports**: Export matched invoices to CSV or A4 Landscape PDF summary reports.
- 🎨 **Appearance Customization**: 6 AAA color themes and 6 professional UI typography fonts.
- 🔒 **Role-Based Security**: Admin vs User access controls with JWT authentication and optional TOTP 2FA.
